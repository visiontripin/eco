# Архив проектов

Материалы, которые не относятся к основному продукту репозитория — **Подработка.МСК**.
Они сохранены как есть, чтобы не терять наработки, и не собираются в CI.

| Проект | Что это | Статус |
|---|---|---|
| [`tws-hub/`](tws-hub/README.md) | Bluetooth-хаб для нескольких колонок: документация, BOM, схема, прошивка Arduino | Инженерный проект, требует обкатки на железе |

Правило простое: новый продукт живёт в корне репозитория, всё экспериментальное —
в `archive/`. Если архивный проект снова становится основным, он возвращается
в корень отдельным репозиторием или папкой `apps/`.
