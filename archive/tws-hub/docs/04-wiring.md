# 04. Схема и распиновка

> Это принципиальная схема в текстовом виде, а не готовая разводка.
> Для первого экземпляра собирайте на макетной плате или перфборде.

## 4.1. Распиновка Arduino

### Arduino Nano Every (рекомендуется)

| Пин | Назначение | Куда |
|---|---|---|
| D0 (RX) / D1 (TX) | `Serial1` | UART к BT-шине |
| D2 | BTN_UP | кнопка → GND |
| D3 | BTN_DOWN | кнопка → GND |
| D4 | BTN_OK | кнопка → GND |
| D5 | BTN_BACK | кнопка → GND |
| D6 | BTN_FN | кнопка → GND |
| D9 | MUX_S0 | 74HC4051 #1 и #2, вход A |
| D10 | MUX_S1 | 74HC4051 #1 и #2, вход B |
| D11 | MUX_S2 | 74HC4051 #1 и #2, вход C |
| D12 | BUZZER | «+» пищалки со встроенным генератором |
| D13 | LED | встроенный светодиод |
| A4 (SDA) | I2C SDA | OLED + PCF8574 |
| A5 (SCL) | I2C SCL | OLED + PCF8574 |
| 5V, GND | питание | — |

### Arduino Nano / Uno (ATmega328P)

Отличие только в UART: D0/D1 заняты USB, поэтому BT-шина уезжает на
**SoftwareSerial: D7 = RX, D8 = TX**. Всё остальное совпадает.

> В `config.h` это переключается одной строкой `TWSHUB_BOARD`.

### Arduino Mega 2560

UART: `Serial1` = D19 (RX) / D18 (TX). Можно завести **4 модуля напрямую**
на `Serial1..Serial3` и не ставить мультиплексор (понадобятся правки в
`bt_bus.cpp`). В базовой прошивке используется только `Serial1`.

## 4.3. Узел мультиплексора и уровней

```
                         ┌──────────────────────────────┐
  Arduino TX (5V)        │                              │
   ─────────────────────▶│ TXB0104  A1 ──── B1  (3V3)   │──▶ Z 74HC4051 #1
                         │          (VCCA=5V, VCCB=3V3) │    (работает как
  Arduino RX ◀── 5V ─────│ TXB0104  A2 ◀─── B2  ◀───────│─── Z 74HC4051 #2
                         └──────────────────────────────┘    (8:1 мультиплексор)

  74HC4051 #1  (TX-демультиплексор 1→8)      74HC4051 #2  (RX-мультиплексор 8→1)
     Z  ◀── TX_3V3                              Z  ──▶ RX_3V3
     Y0..Y7 ──▶ UART_RX слотов 0..7             Y0..Y7 ◀── UART_TX слотов 0..7
     VCC = 3.3 В, GND, /E = GND                 VCC = 3.3 В, GND, /E = GND
     A/B/C ◀── S0/S1/S2 от Arduino              A/B/C ◀── те же S0/S1/S2
```

**Почему нужен преобразователь уровней.** BT-модуль — 3.3 В. Arduino — 5 В.
У ATmega4809 порог логической единицы 0.7·VDD = **3.5 В**, то есть 3.3 В от
модуля может не читаться. У ATmega328P порог 0.6·VDD = 3.0 В — проходит
впритык, но на грани. Не экономьте $1.5 на TXB0104.

**Бюджетный вариант** вместо TXB0104:
* TX (5 В → 3.3 В): делитель 2.2 кОм / 3.3 кОм;
* RX (3.3 В → 5 В): буфер **74HCT125**, питаемый от 5 В (у HCT входной
  порог TTL 2.0 В, он гарантированно понимает 3.3 В).

## 4.4. Аудиошина

### Вариант 1: I2S (рекомендуется)

```
  SLOT0 (Sink, I2S MASTER)          SLOT1..N (Source, I2S SLAVE)
  ┌────────────────┐                ┌─────────┐ ┌─────────┐
  │ I2S_CLK   ─────┼───────────────▶│ I2S_CLK │ │ I2S_CLK │   BCLK  1.536 МГц
  │ I2S_WS    ─────┼───────────────▶│ I2S_WS  │ │ I2S_WS  │   LRCK  48 кГц
  │ I2S_OUT   ─────┼───────────────▶│ I2S_IN  │ │ I2S_IN  │   DATA
  └────────────────┘                └─────────┘ └─────────┘
```

Настройка через AT:
* SLOT0: `AT+I2SCFG=1` — I2S **Master**, 48 кГц, 16 бит, BCLK = 1.536 МГц;
* SLOT1..N: `AT+I2SCFG=3` — I2S **Slave**, 48 кГц, 16 бит.

Биты `AT+I2SCFG`: BIT0 — включить, BIT1 — slave, BIT2 — 44.1 кГц,
BIT3 — right justified, BIT4 — data no delay, BIT5..6 — разрядность.
Примеры из документации: `1` = master/48k/16bit, `3` = slave/48k/16bit,
`65` = master/48k/32bit, `67` = slave/48k/32bit
[3](https://document.feasycom.com/docs/audio/BT1026_EN/latest/BT1026_programming_user_guide.html).

**Общий клок — необходимое условие**, чтобы все передатчики кодировали
один и тот же сэмпл в один момент. Это не даёт синхронности воспроизведения
(см. [05](05-sync-and-latency.md)), но убирает один источник разброса.

Держите длину BCLK до 10 см, а лучше — резистор 33–100 Ом в разрыв линии
у источника, чтобы не ловить звон и переотражения.

### Вариант 2: аналог (проще, но хуже)

```
  SLOT0: SPK_LP/LN, SPK_RP/RN  ──▶  развязывающие конденсаторы 10 мкФ
                                    (дифференциальный выход!)
                                              │
                              ┌───────────────┴───────────────┐
                              ▼                               ▼
                   SLOT1 MIC_LP/RP + MICBASE        SLOT2 MIC_LP/RP + MICBASE
```

Выходы у модуля **дифференциальные** (SPK_LP/LN, SPK_RP/RN), входы тоже.
Схема соединения differential-out → differential-in:

```
  SPK_LP ────▶ MIC_LP        SPK_RP ────▶ MIC_RP
  SPK_LN ────▶ MIC_LN        SPK_RN ────▶ MIC_RN
  GND    ────▶ MIC_BASE
```

Если нужна «земля-референсная» (недифференциальная) передача, берите
только «P»-выводы, а «N» через конденсатор 1 мкФ на землю — но уровень
станет вдвое меньше и шумы вырастут.

**Минус аналога:** каждый АЦП в передатчике работает от своего клока, и
к тому же добавляется задержка АЦП (единицы-десятки мс). Для `TOPO_MULTI`
это не критично, для `TOPO_DUAL` — лучше I2S.

## 4.5. Кнопки

```
  5V ──┐ (не нужно: используем внутреннюю подтяжку)
       │
  D2 ──┴──[кнопка]── GND      BTN_UP      (INPUT_PULLUP, активный LOW)
  D3 ──┴──[кнопка]── GND      BTN_DOWN
  D4 ──┴──[кнопка]── GND      BTN_OK
  D5 ──┴──[кнопка]── GND      BTN_BACK
  D6 ──┴──[кнопка]── GND      BTN_FN
```

Конденсатор 100 нФ параллельно каждой кнопке не помешает, если провода
длиннее 10 см. Программный антидребезг в прошивке уже есть (25 мс).

## 4.6. Дисплей и расширитель

```
  A4 (SDA) ──────────────┬──── SDA  OLED SSD1306 (адрес 0x3C)
  A5 (SCL) ──────────────┼──── SCL  OLED
                         ├──── SDA  PCF8574 (адрес 0x20, опция)
                         └──── SCL  PCF8574
  5V / GND ────────────────── VCC/GND обоих
```

Подтяжки 4.7 кОм на SDA и SCL к 5 В, если их нет на модулях.

## 4.7. Питание

```
  5 В / 2 А ──┬──▶ Arduino 5V (или USB)
              ├──▶ OLED, PCF8574, пищалка
              └──▶ DC-DC 3.3 В / 2 А ──┬──▶ VDD всех BT-модулей
                                       └──▶ VCC обоих 74HC4051, TXB0104 (VCCB)

  Развязка: 100 нФ + 10 мкФ на каждый BT-модуль, прямо у выводов VDD/GND.
  Общая земля — звездой, в одной точке. Землю аудио не путать с цифровой.
```

DC-DC понижающий (на MP2307 / LM2596 с фиксированным 3.3 В) — обязателен:
линейный AMS1117 при 0.5 А рассеет (5−3.3)·0.5 = 0.85 Вт и уйдёт в защиту.

## 4.8. Опциональная схема питания слотов

```
  3V3 ──── source (P-MOSFET AO3401)
              │ drain ──▶ VDD слота
              gate ──[10 кОм]── 3V3
              │
              └── collector/выход PCF8574 (LOW = включено)
```

PCF8574 управляется по I2C с той же шины, что и OLED. В базовой версии
прошивки этот узел описан, но не задействован — оставлен как понятная
точка расширения.

## 4.9. Типовые ошибки монтажа

| Симптом | Причина |
|---|---|
| Модуль не отвечает на `AT` | питание 5 В вместо 3.3 В — модуль сгорел |
| Отвечает мусором | не совпадает скорость UART (по умолчанию 115200) |
| Кракозябры в ответах | нет преобразователя уровней |
| Звук есть, но тихий и искажённый | аналог подключён «P» без «N», потеряно 6 дБ |
| Слоты «слышат» чужие команды | перепутаны линии S0/S1/S2 или /E не посажен на GND |
| Модуль уходит в ребут | просадка 3.3 В на старте — нужен DC-DC и конденсаторы |
