# 09. FAQ, риски и известные грабли

## 9.1. Частые вопросы

**В: Можно ли обойтись одним BT-модулем, который и принимает, и передаёт?**
Нет. В Bluetooth-стеке Feasycom A2DP Sink и A2DP Source **взаимоисключающие**
роли [1](https://document.feasycom.com/docs/audio/BT1036_EN/latest/user-instructions.html).
Минимум два модуля: один на приём, один на передачу. Это общее
ограничение Classic Audio, а не конкретного вендора.

**В: А если взять ESP32 — он же мощнее?**
ESP32 не умеет одновременно быть A2DP-приёмником и A2DP-источником
[3](https://github.com/pschatzmann/ESP32-A2DP/discussions/286), а
многопоточная раздача A2DP требует переделки Bluedroid и упирается в
ограничения стека [2](https://github.com/espressif/esp-idf/issues/2060).
ESP32 может быть **приёмником** (SLOT0) вместо Feasycom — это допустимая
замена, но передатчики всё равно нужны отдельные.

**В: Почему колонки играют вразнобой? Я же подал им один сигнал!**
Потому что общий сигнал ≠ общий момент воспроизведения. Каждая колонка
сама решает, сколько набрать в буфер. См. [05](05-sync-and-latency.md).

**В: Можно ли сделать 10 колонок синхронно?**
Только Auracast (`TOPO_AURACAST`) или вендорский party-режим
(`TOPO_PARTY`). На независимых A2DP-линках — нет.

**В: Будет ли работать с колонками разных фирм?**
`TOPO_MULTI` — да. `TOPO_DUAL` — да, если модуль держит два линка.
`TOPO_PARTY` — **нет**, нужна одна экосистема. `TOPO_AURACAST` — только
если колонки поддерживают Auracast.

**В: Сколько колонок максимум?**
Аппаратно — 7 (8 слотов минус один на приём). Увеличить можно, поставив
второй мультиплексор на ещё 8 слотов (понадобится 4-я линия выбора) —
но см. вопрос про рассинхрон: в одной комнате это бессмысленно.

**В: Не проще ли купить готовый передатчик за $30?**
Если нужно ровно 2 колонки — да, проще. 1Mii B06T6 или Avantree HT4189
решают задачу «две колонки/наушника из коробки»
[1](https://manuals.plus/asin/B0BJZFSRYN)
[4](https://avantree.com/products/ht4189-bluetooth-tv-headphone-transmitter-set).
Этот проект имеет смысл, когда вам нужны: список колонок в EEPROM,
индивидуальное включение, дисплей, N > 2, или просто интересно разобраться.

**В: А зачем тогда Arduino, если всё делает BT-модуль?**
Затем, что BT-модуль без управления сам по себе — это коробка с одной
кнопкой. Arduino даёт список колонок, их имена, индивидуальное
включение, индикацию состояния, автопереподключение, диагностику.

**В: Какая реальная задержка от телефона до колонки?**
Две задержки подряд: телефон → хаб и хаб → колонка. Каждая по
[таблице](05-sync-and-latency.md#51-из-чего-складывается-задержка-связки-источник--колонка).
На SBC это ~200 мс + ~200 мс = **~400 мс**. Для музыки всё равно, для
видео/игр — не годится. Для ТВ берите aptX-LL / aptX-Adaptive или Auracast.

**В: Можно ли убрать вторую задержку (хаб → колонка)?**
Можно снизить, выбрав быстрый кодек, но не убрать. Это цена беспроводной
передачи.

**В: А если колонки с AUX-входом тогда зачем BT?**
Тогда лучше Auracast + приёмники (Avantree AuraLink)
[4](https://avantree.com/products/auralink-bluetooth-auracast-receiver):
синхронно, любое число колонок, задержка 20–50 мс.

**В: Нужен ли мне лицензионный aptX?**
Если модуль заявляет aptX/aptX-HD/aptX-LL, лицензия обычно уже оплачена
вендором модуля (у Feasycom в описании BT1026B прямо сказано
«aptX LL (license required)»
[5](https://www.feasystore.com/product/fsc-bt1026b/)). Уточняйте при заказе:
модуль «с aptX» без лицензии официально нелегален и может не собраться
с нужной прошивкой.

## 9.2. Риски проекта

| Риск | Вероятность | Влияние | Митигация |
|---|:--:|:--:|---|
| Модуль не поддерживает A2DP Source | средняя | **проект останавливается** | проверить на шаге 2 [08](08-bringup.md), до заказа партии |
| Нет dual-link | высокая | DUAL недоступен | переходить на PARTY / AURACAST |
| Ответы AT отличаются от документации | высокая | парсер не работает | снять логи через USB-UART, поправить `slotScanNext()` и ожидаемые токены |
| Рассинхрон в одной комнате | **высокая** для MULTI | эхо | не использовать MULTI в одной комнате |
| Просадка 3.3 В | средняя | ребуты модулей | DC-DC 2 А + конденсаторы у каждого модуля |
| Наводки на I2S | средняя | хрип, щелчки | короткие линии, 33–100 Ом в разрыв BCLK, раздельная земля |
| Помехи 2.4 ГГц от Wi-Fi | средняя | заикания | отдалить от роутера, использовать 5 ГГц Wi-Fi, канал 1/6/11 |
| Не влезает в ОЗУ (Nano 328P) | средняя | нестабильность | взять Nano Every, или урезать `MAX_SPEAKERS` до 8 (экономит 224 байта) |
| Кириллицы нет в шрифтах | **100 %** | меню на латинице | см. [07](07-ui.md#76-кириллица--важное-ограничение) |

## 9.3. Известные ограничения текущей прошивки

1. **Маршрутизация каналов (L/R) помечена, но не реализована.** Поле
   `Channel` в базе есть, но реально левый/правый канал никуда не
   распределяется: это требует управления аудиопотоком внутри модуля
   (часть поддерживается через `AT+`-команды конкретных прошивок).
2. **Trim (подстройка громкости) хранится, но не применяется.** Нужно
   мапить его на `AT+MICGAIN` / `AT+SPKVOL` — делается в одном месте
   (`audio_core.cpp`, фаза `PH_STREAM_WAIT`).
3. **Нет автопереподключения при обрыве.** `audioCoreTick()` уже видит
   состояния линков, добавить реконнект — ~20 строк.
4. **PCF8574 (питание слотов) не задействован** — только описан в
   [04](04-wiring.md#48-опциональная-схема-питания-слотов).
5. **Парсер `+SCAN=`** рассчитан на формат `+SCAN=<MAC>,<rssi>,<name>`.
   В реальности бывает `+SCAN=<MAC>,<name>` или с кавычками — проверьте
   глазами и поправьте `slotScanNext()`.
6. **Топология меняется «для следующего подключения»**: после смены в меню
   нужно выполнить `Connect all`, чтобы профили переехали.

## 9.4. Идеи для развития

| Что | Сложность | Комментарий |
|---|:--:|---|
| Автопереподключение при обрыве | низкая | мониторинг уже есть |
| Применение `Trim` через `AT+MICGAIN` | низкая | |
| Watchdog на зависший модуль (перезагрузка по питанию) | средняя | нужен PCF8574 + MOSFET |
| Полный U8g2 + иконки | средняя | только Nano Every |
| Веб-интерфейс вместо дисплея (ESP32 как сопроцессор) | высокая | ESP32 по UART к Arduino |
| Auracast-передатчик на nRF5340 | высокая | [AuraPlug](https://www.hackster.io/alexlynd/auraplug-synchronized-le-audio-563657) как референс |
| Печатная плата (4 слоя, раздельные земли) | средняя | после обкатки на макете |

## 9.5. Краткая памятка

```
1. Arduino не касается звука.              — это не баг, это архитектура
2. Синхронность = топология, а не код.     — выберите её ДО закупки
3. Sink и Source — разные модули.          — минимум два
4. Независимые линки = эхо в одной комнате.
5. Для ТВ нужен aptX-LL или Auracast.      — SBC даст ~400 мс
6. Проверьте A2DP Source до заказа партии модулей.
```
