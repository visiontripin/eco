# Подработка.МСК — Сервис поиска подработок и быстрых смен

Онлайн-платформа поиска подработок по **Москве и Московской области** с заложенной в БД международной гео-архитектурой (`regions`, `locations`, ISO-коды стран, валюты, часовые пояса и локали).

## Основные возможности (MVP+)
- **Витрина и поиск смен**: мгновенный полнотекстовый поиск, фильтрация по станциям метро Москвы и МЦД / городам МО (Химки, Мытищи, Люберцы, Красногорск, Одинцово, Домодедово), категории, оплата за смену, даты (`На сегодня`, `На завтра`, `Ближайшие дни`), способ прямой выплаты (`СБП сразу`, `На руки`, `На карту СМЗ`), бейджи `Без опыта`, `Проверенные ★`, `Избранные`.
- **Прямые выплаты + тарифная монетизация**: 0% комиссии с заработка исполнителей, гибкие тарифы с реальными лимитами (`Бесплатный`, `Про 299 ₽`, `Старт`, `Бизнес 1 990 ₽`).
- **Личный кабинет Работника**: учёт заработка по закрытым сменам, активные смены, честный рейтинг и индекс выходов (`Show-up rate`), отклики, мини-чат с работодателем, взаимные оценки, избранные вакансии.
- **Личный кабинет Работодателя**: публикация смен с автоматическим расчётом часовой ставки, командный набор `N из M` человек, клонирование смен на завтра, пауза/возобновление, воронка кандидатов с приоритетом `PRO`, закрытие смен и оценка работников.
- **Админ-панель и Модерация**: живая очередь модерации отзывов с мгновенным пересчётом рейтингов, редактирование тарифов и лимитов, выдача статуса «Проверенный работодатель», управление регионами международного масштабирования в SQLite БД.

## Запуск проекта
```bash
npm install
npm run dev
```
Приложение и API запускаются на едином порту `http://0.0.0.0:3000`.
