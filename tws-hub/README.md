# TWS-HUB — Bluetooth-хаб для нескольких колонок

## Что получается

Устройство с OLED-экраном и пятью кнопками, которое:

* принимает звук по Bluetooth от телефона или ТВ (или по проводу: AUX / оптика);
* раздаёт его в **несколько** Bluetooth-колонок;
* помнит колонки в EEPROM (до 16 штук), позволяет включать/выключать
  каждую, задавать канал (mono/L/R) и подстройку громкости;
* показывает состояние: сколько линков поднято, какой кодек, что играет.

## Главное, что нужно знать до покупки деталей

**1. Arduino не обрабатывает звук. И не может.**
ATmega328P (Nano/Uno) — 16 МГц и 2 КБ ОЗУ. Одного только SBC-декодера
нужно десятки килобайт ОЗУ. Arduino здесь — только «дисплей + кнопки +
UART-дирижёр», который отправляет AT-команды Bluetooth-модулям.
Звук течёт между модулями по I2S или аналогу, **мимо** микроконтроллера.

**2. Синхронность — это вопрос топологии, а не кода.**
Классический Bluetooth A2DP — соединение точка-точка, один источник —
один приёмник. Он **не умеет** широковещательно рассылать один поток на
несколько устройств синхронно [5](https://moschip.com/blog/device-software-engineering/what-is-auracast-and-how-it-helps-bluetooth-le-audio-enabled-broadcast/).
Если вы поставите N независимых передатчиков, каждая колонка будет иметь
**свою собственную, случайную задержку** (десятки-сотни миллисекунд), и
в одной комнате это будет слышно как эхо.

Решения, которые действительно дают синхронный звук:

| Колонок | Как | Синхронность |
|---|---|---|
| 2 | Один чип держит **оба** линка (dual-link / TWS) | да, единицы мс |
| 2–4+ одной фирмы | Хаб → мастер-колонка → PartyBoost / PartyCast / Party Chain | да, вендорский синк |
| Любое число | **Auracast** (LE Audio, BIS) — если колонки/приёмники его поддерживают | да, по стандарту |
| Любое число, в **разных комнатах** | N независимых A2DP-линков | не нужно: вы их не слышите одновременно |
| Любое число, в **одной комнате** | N независимых A2DP-линков | **нет, будет эхо** |

Подробности, расчёты и ссылки — в [docs/01](docs/01-concept-and-limits.md)
и [docs/05](docs/05-sync-and-latency.md).

```
tws-hub/
  docs/            проектная документация (01..09)
  firmware/
```

## Быстрый старт

1. Прочитать [docs/01](docs/01-concept-and-limits.md) и выбрать топологию.
2. Купить детали по [docs/03](docs/03-bom.md).
3. Собрать по [docs/04](docs/04-wiring.md).
4. В `firmware/tws_hub/config.h` выставить `TWSHUB_BOARD`.
5. Залить `tws_hub.ino`, открыть Serial Monitor 115200, нажать `h`.
6. Пройти [docs/08](docs/08-bringup.md).
