# 07. Дисплей и интерфейс

## 7.1. Что показываем

Дисплей: **OLED SSD1306 128×64 по I2C**. В прошивке используется библиотека
**U8g2 в режиме U8x8** — это текстовый режим 16×8 символов **без
framebuffer**.

Почему именно так:

| Режим | ОЗУ под дисплей | Возможности |
|---|--:|---|
| U8x8 (текст, выбран) | ~0 байт | 8 строк по 16 символов, инверсия |
| Adafruit_GFX + SSD1306 | **1024 байта** | графика, но это половина ОЗУ ATmega328P |
| U8g2 полный (picture loop) | 1024 байта + | графика, иконки |

На Nano Every (6 КБ ОЗУ) можно перейти на полный U8g2 и рисовать иконки
уровня/заряда. На Nano/Uno (2 КБ) — **только U8x8**.

## 7.2. Главный экран

```
┌────────────────┐
│▓TWS-HUB v0.4  ▓│  ← инверсная шапка
│ SRC  playing   │     состояние входа (BT / AUX)
│ SPK  2/3  play 2│     линков поднято / всего, сколько реально играют
│ TOPO multi     │     dual / multi / party / auracast
│ CODEC SBC      │     кодек первого играющего линка
│ RAM   1246 b   │     свободная память
│ UP     1287 s  │     аптайм
│ OK=menu FN=link│     подсказка по кнопкам
└────────────────┘
```

Во время подключения строки 5–6 заменяются на фазу и прогресс-бар:

```
│ connecting     37%│
│ [######..........]│
```

## 7.4. Назначение кнопок

| Кнопка | HOME | Списки | Поиск |
|---|---|---|---|
| UP | запустить подключение | вверх (с автоповтором) | — |
| DOWN | запустить подключение | вниз (с автоповтором) | следующая найденная |
| OK | войти в меню | выбрать | добавить найденную |
| BACK | — | назад / на экран выше | выход |
| BACK (долгое) | — | сразу на HOME | выход |
| FN | запустить подключение | — | начать поиск |

Логика в `buttons.cpp`: антидребезг 25 мс, длинное нажатие от 600 мс,
автоповтор для UP/DOWN — задержка 900 мс, далее каждые 180 мс.

## 7.5. Поля в базе колонок

| Поле | Смысл |
|---|---|
| MAC | адрес Bluetooth, 6 байт |
| Name | до 15 символов, показывается в списке |
| Enabled | участвует в «Connect all» или нет |
| Channel | `mono` / `L` / `R` — для будущей маршрутизации стерео; в текущей версии только помечает |
| Trim | −12…+12 дБ, задел под analog gain (`AT+MICGAIN`) |
| Pref. slot | закрепить колонку за конкретным слотом |

Хранится в EEPROM: 8 байт заголовка + до 16 записей по 28 байт = 456 байт
(в ATmega328P EEPROM — 1024 байта, влезает). Контрольная сумма CRC-8
пересчитывается при каждом `dbCommit()`.

## 7.6. Кириллица — важное ограничение

**Стандартные шрифты U8g2 кириллицы не содержат.** В базовой поставке
меню — латиницей (`TWS-HUB`, `Speakers`, `Connect all`, `Topology`).

Как добавить русский:

**Вариант 1 (простой).** Оставить интерфейс латиницей, а имена колонок
писать транслитом. Ничего делать не надо.

**Вариант 2 (правильный).** Собрать свой шрифт:

1. Взять BDF-шрифт с кириллицей (например из пакета `xfonts-cyrillic`:
   `*-fixed-medium-r-normal--*-*-*-*-c-*-koi8-r`).
2. Сконвертировать его утилитой `bdfconv` из состава U8g2:

   ```
   bdfconv -v -f 1 -m '32-255' -o my_font.c font.bdf
   ```

   Диапазон `-m` задайте по вашей кодировке. Для UTF-8 прошивки нужно
   `-m '32-127,1040-1103'` (диапазон кириллицы UTF-8/Unicode).
3. Подключить полученный `.c` к скетчу и заменить
   `u8x8.setFont(u8x8_font_chroma48medium8_r)` на свой.
4. **Важно:** в U8x8-режиме (без framebuffer) доступны только 8×8 шрифты,
   поэтому кириллица влезет, но символы будут плотными. Для нормального
   вида понадобится полный U8g2 → **только Nano Every** (6 КБ ОЗУ).

**Вариант 3 (обойти).** Вывести меню на русском, но транслитерировать
строки на стороне прошивки таблицей замены. Работает без пересборки
шрифтов, но выглядит так себе.

## 7.7. Энергосбережение

Через 30 с без нажатий (`UI_IDLE_MS`) дисплей гасится (`setPowerSave(1)`).
Любое нажатие включает его обратно. Отключается в
`Settings → Auto-dim`.

OLED SSD1306 при выключенной подсветке потребляет десятки микроампер, так
что гасить имеет смысл, если хаб работает от аккумулятора.

## 7.8. Что можно улучшить

| Идея | Сложность |
|---|---|
| Иконки уровня линка (RSSI) | средне, нужен полный U8g2 |
| Показывать название трека через AVRCP (`AT+TRACK`) | средне |
| Громкость каждой колонки отдельно | средне (нужен AVRCP absolute volume) |
| Русский шрифт | средне/высоко |
| Автопереподключение при обрыве линка | низко (уже есть задел: `audioCoreTick()` мониторит состояния) |
| Веб-интерфейс вместо дисплея | высоко, потребует ESP32 |
